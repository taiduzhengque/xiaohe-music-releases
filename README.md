# 小何音乐

Windows 本地音乐播放器的官方发行与自动更新仓库。源码保持私有；此仓库只提供程序与更新文件。

[下载最新正式版本](https://github.com/taiduzhengque/xiaohe-music-releases/releases/latest)

## 安装与使用

下载发行页中的 XiaoheMusic-v版本-win-x64.zip，完整解压后运行根目录的小何音乐.exe。也可选择 Setup.exe 安装。请保留 current、Update.exe 和随包运行库；无需另装 .NET。三维壁纸与网页能力使用系统 WebView2 Runtime。

支持本地曲库、拖入播放、收藏与多标签、均衡器、歌词／海报匹配、清晰壁纸、全屏滤镜及音乐视效。普通启动保持静默；音频源文件保持原位。

## 更新与历史版本

播放器启动时检查正式更新，播放或导入期间暂缓自动重启。每个发行版包含安装程序、便携ZIP、SHA256和完整更新包等六项文件。历史正式发行用于更新验证及回退，请按完整版本下载，不混用内部组件。

音乐、数据库、账号、私有验收资料和开发运行时不会发布到这里。请在反馈问题时提供版本、Windows版本、重现步骤及报错；不要提交个人音乐或账户信息。
